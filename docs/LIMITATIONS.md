# IsaWitness: current limitations

> Documentation preparation draft.

## Scope limits

The 771-form inventory and ObsGen observation/projection equations do not certify all instructions end to end. Per-form step proofs remain deferred, and the moving value, instruction-class, generator, physical-memory and walk-cleanup layers and program/library releases are excluded. Physical processors and consumers still require their own exact premises and evidence.

Recorded runtime choices and source corrections are part of the frozen semantic target. Exact-rational real execution and exact-only square-root support have explicit domain limitations. Retained runtime optimizations do not certify excluded FSQRT instructions. Finite Isla comparisons are cross-validation, not a complete translation-correctness proof.

## Finite evidence remains qualified

The ledger retains 441 partial forms. Selected ordered traces retain 2 mismatches and 32 partials, while architectural comparisons retain 65 partials. Ordinary CSDB/SSBB mismatches are preserved. These finite, historically sourced report projections do not prove all-input equivalence, native instruction equivalence, constant-time behavior, exact write sets or total correctness for a consumer.

## Frozen diagnostic strings

The frozen generated model retains 2244 build-path string literals across 306 modules. They are assertion-message data from the original generation. A comment-aware scan of all 1496 frozen model/runtime/test sources classified the path hits inside strings, checked their assertion call contexts and found no file-read, include, initialization or evaluation hook using them. They do not require the original generation directories to exist.

The earlier unchanged-module spot build, ArmFull.Fn.M0155, reproduced canonical artifact SHA256 11731e5bb7287c2d034d89ba9295edd3895f426e68b5190c234151b30f95c223. The completed cold build now separately reports all 1481 canonical model artifact hashes matching; this broader result is backed by its completed receipt, rather than extrapolated from the spot check.

This checkpoint preserves the frozen model bytes, including inert diagnostic strings. Path normalization is deferred to the next planned model revision, with regeneration, review, fresh builds/gates and consumer migration. The public runtime and observer copies separately record opening-comment normalization. Raw private generation paths and internal review records are kept out of these documentation pages.
